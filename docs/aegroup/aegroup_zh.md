# 电子科技大学算法工程小组
我在算法与逻辑实验室指导 **算法工程小组**。

根据 Wikipedia 的定义，[**算法工程**](https://en.wikipedia.org/wiki/Algorithm_engineering) 是一门关注计算机算法的设计、分析、实现、优化、性能剖析和实验评估的学科，旨在弥合算法理论与算法实际应用之间的差距。

例如，我们已经构建了一些高性能程序，用于求解：

1. 松弛团问题。
2. Steiner 树问题。
3. 二维和三维下料问题。
4. 卫星调度问题。

### 给未来学生的建议
- 本科生：电子科技大学本科生全年都可以来我的办公室找我，或给我发邮件。需要注意的是，科研训练主要是为硕士或博士阶段学习做准备。
- 硕士生：如果你考虑选择我作为硕士阶段导师，这里有一些建议。
    1. 确认喜欢组合问题求解、算法设计和分析。
    3. 每周能参加团队活动，每学期能有一个月的时间参与科研训练。
